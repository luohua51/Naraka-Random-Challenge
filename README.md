🎲 洛花庄园随机抽取挑战 (Naraka Random Challenge) V3.1 更新说明
欢迎体验《永劫无间》专属的随机挑战抽取工具！本项目是一个纯前端网页，无需配置任何服务器，下载即用，数据全部保存在本地浏览器中，安全可靠。

🚀 V3.1 新特性 (What's New)
作为项目的第三版，本次更新带来了大量体验与功能上的升级：
  🎨 视觉与 UI 全面重构：彻底告别之前的杂色（青色/粉色），全面采用《永劫无间》官网风格的暗红+暗金国风配色。界面布局整体上移，设置栏直接外露，操作更加便捷。
  ✏️ 自定义标题：点击主标题右侧的“✎”图标，即可随时修改网页标题（如改成你自己的战队名），修改后自动保存在本地。
  📁 选手名单分组管理（多套名单无缝切换）：
    支持“先建分组再编辑”或“编辑后保存为分组”。
    底部下拉框随时切换不同玩家群体的名单（如“第一波”、“第二波”），选择即导入。
    支持一键删除不需要的分组（若删除的是当前正在使用的分组，会自动转为临时名单，不影响抽卡）。
  🖼️ 历史记录卡片大改版：
    底部历史面板加高，支持按“轮次”分组（当前轮次置顶）。
    小卡片重构为：16:9 英雄缩略图 + 左侧信息（英雄/选手/F/武器）+ 右侧操作按钮（回放/删除），信息展示更饱满、紧凑。
    新增单条记录“删除”功能，防止误抽或记录冗余。
  🎛️ 可视化开关：将原本的复选框全部替换为药丸式滑动开关，亮起代表开启，暗下代表关闭，状态一目了然。


📖 完整功能指南 (Full Feature Guide)
1. 核心抽取机制
多维度抽取：同时抽取【选手】、【英雄】、【技能 F】、【奥义 V】、【近战武器】、【远程武器】。
老虎机动画：每个槽位拥有独立滚轮动画，结果展示时带有专属聚光灯特效与英雄语音（需本地有音频文件）。
双刀流模式：开启后，远程武器槽位会变为“近战2”，抽取两把不一样的近战武器。
2. 抽取规则与轮次
防重复机制：可独立开启【选手不重复】与【英雄不重复】。
自动/手动轮次：当不重复选项的池子被抽干，系统会自动进入下一轮并清空去重记录；也可随时点击【开启新一轮】重置状态。历史记录会按轮次严格归档。
3. 深度自定义系统
自定义选手：
支持自由添加、删除选手。
支持本地图片上传（存为 Base64），抽取结果会展示选手专属头像。
名单库：支持建立多套名单档案，随时导入替换。
自定义池子：支持自由勾选哪些英雄、哪些近战、哪些远程武器参与抽取，打造专属的“神仙局”或“纯刀局”。
4. 历史记录与回放
全量记录：底部面板显示最近记录，点击“全部记录”可查看历史所有抽取结果。
一键回放：点击历史卡片，重新展示当时的抽取结果、动画和语音。
单条/全量删除：支持删掉手滑抽错的单条记录，或一键清空所有历史。
5. 其他实用功能
音频系统：支持英雄出场语音，右上角提供一键静音按钮。
本地存储：所有自定义的选手、分组、历史记录、甚至是修改后的标题，均使用 localStorage 和 sessionStorage 保存在浏览器中，刷新页面不会丢失。
